### [KetchUp：Rust 与 WebGPU 构建的开源 SketchUp 替代品](https://ketchup3d.github.io/app/) ⭐️ 7.0/10

KetchUp 是一个开源、面向浏览器的 3D 建模工具，定位为 SketchUp 的替代品，技术栈为 Rust 与 WebGPU。该项目的 Hacker News 条目链接到网页应用，讨论者称其 Rust 界面在浏览器中的响应和文字渲染表现令人印象深刻。当前没有独立基准或完整功能清单，因此实际建模能力、兼容性和成熟度仍不明确。

hackernews · dcoulmbe · 11月8日 22:35 · [社区讨论](https://news.ycombinator.com/item?id=50418176)

**「背景」** KetchUp 的 GitHub 项目页将其描述为免费、开源的 3D 建模软件和 SketchUp 替代品，采用 Rust、WebAssembly 与 WebGPU 构建，可在浏览器或桌面运行；一份项目摘要还称它无需账号，并能导入 SketchUp 的 .skp 几何体、导出 Wavefront OBJ。对已有 SketchUp 工作流的用户来说，这意味着可以在浏览器中沿用同类建模方式，而不必先转换到另一种文件格式。

**「影响」** 对需要制作盒子、外壳等简单几何的 3D 打印用户，浏览器内建模可省去安装桌面软件；但已有试用反馈指出，画矩形后会要求命名对象，默认交互仍需调整。

**「社区讨论」** 评论整体正面：有人称它是 SketchUp 的精神续作，也有人赞叹 Rust UI 在浏览器中的手感与文字渲染。另有用户反馈画矩形时被要求命名对象，认为这不是合理的默认行为。
